# 页面结构

## 产品定位

**一句话：** 面向 AI 产品经理岗位的个人品牌站，用「产品思维 + Vibe Coding 落地能力」证明既能定义 AI 产品，也能亲手做出来。

**访客心智：** 招聘方 30–60 秒内应看到——你是谁、你做 AI 产品的方法论、可验证的项目成果、可协作的技术栈、如何联系你。

---

## 整体布局

单页滚动（Landing + Anchor），顶部固定导航跳转各区块。

```
┌─────────────────────────────────────────┐
│  Nav（Logo / 锚点 / CTA「联系我」）        │
├─────────────────────────────────────────┤
│  01 Hero                                 │
│  品牌名 + 一句定位 + 短支撑句 + CTA        │
│  全宽科技氛围视觉（非卡片拼贴）            │
├─────────────────────────────────────────┤
│  02 About — 个人介绍                     │
│  经历叙事 + 产品观 + 一张真实人设/工作图    │
├─────────────────────────────────────────┤
│  03 AI Capabilities — AI 能力展示         │
│  能力矩阵（产品 / 模型 / 工程 / 增长）     │
├─────────────────────────────────────────┤
│  04 Projects — 项目作品                   │
│  2–4 个重点项目（问题→方案→指标→你的角色） │
├─────────────────────────────────────────┤
│  05 Skills — 技术能力                     │
│  Vibe Coding 栈 + 工具链可视化            │
├─────────────────────────────────────────┤
│  06 Contact — 联系方式                    │
│  邮箱 / 微信 / LinkedIn / 简历下载         │
├─────────────────────────────────────────┤
│  Footer                                  │
└─────────────────────────────────────────┘
```

---

## 导航结构

| 位置 | 内容 |
|------|------|
| 左侧 | 品牌名（如 `YOURNAME` 或 `ONEPERSON`） |
| 中间 | About / Capabilities / Projects / Skills |
| 右侧 | 主按钮「Contact」或「Let's talk」 |

**移动端：** 汉堡菜单 + 抽屉（Sheet）。

---

## 各区块信息架构

### 01 Hero

| 项 | 说明 |
|----|------|
| **目的** | 第一印象与定位 |
| **核心内容** | 姓名/品牌、角色标签（AI Product Manager）、一句价值主张、主 CTA「查看作品」+ 次 CTA「下载简历」 |
| **交互** | 轻微入场动效；滚动指示 |
| **文案骨架** | Brand → Headline → Support → CTA |

**文案示例（可替换）：**

- Brand: `张三` / `Alex Chen`
- Headline: `AI Product Manager who ships.`
- Support: `用产品定义 AI 体验，用 Vibe Coding 把想法做成可用产品。`
- CTA: `查看项目` / `获取简历`

---

### 02 About — 个人介绍

| 项 | 说明 |
|----|------|
| **目的** | 建立信任与人设 |
| **核心内容** | 3–5 句个人故事；产品原则（3 条）；可选时间线（1–2 段关键经历） |
| **交互** | 文字为主，配一张工作/思考场景图 |
| **布局** | 桌面：左文右图；移动：上文下图 |

---

### 03 AI Capabilities — AI 能力展示

| 项 | 说明 |
|----|------|
| **目的** | 证明「懂 AI 产品」 |
| **核心内容** | 4 组能力：需求洞察与 PRD、Prompt/Agent 设计、评测与数据闭环、从 0 到 1 落地 |
| **交互** | 列表/网格，悬停微动效，非卡片堆叠感 |

**能力分组建议：**

1. **需求洞察与 PRD** — 用户研究、场景拆解、AI 产品需求文档
2. **Prompt / Agent 设计** — 提示词工程、工作流、多 Agent 协作
3. **评测与数据闭环** — 评测集、指标、反馈驱动迭代
4. **从 0 到 1 落地** — Vibe Coding、原型验证、快速上线

---

### 04 Projects — 项目作品

| 项 | 说明 |
|----|------|
| **目的** | 证明「做过且能讲清」 |
| **核心内容** | 每个项目：标题、一句话、角色、技术标签、关键结果、详情展开或外链 |
| **交互** | 项目为可交互容器（允许卡片）；详情可用 Sheet/Dialog |
| **数量建议** | 首版 2–3 个精品项目 |

**单项目叙事结构：**

```
问题（Why）→ 方案（How）→ 指标/结果（Impact）→ 你的角色（Role）
```

---

### 05 Skills — 技术能力

| 项 | 说明 |
|----|------|
| **目的** | 证明 Vibe Coding 能力 |
| **核心内容** | Frontend / AI Tools / Product Tools 三层；熟练度用简洁条或标签 |
| **交互** | 分组标签，避免技能雷达图花哨 |

**技能分组建议：**

| 分组 | 示例 |
|------|------|
| Frontend | Next.js、React、TypeScript、Tailwind、shadcn/ui |
| AI Tools | Cursor、Claude、GPT、Prompt Engineering、LangChain / Agent |
| Product Tools | Figma、Notion、PRD、数据分析、A/B 实验 |

---

### 06 Contact — 联系方式

| 项 | 说明 |
|----|------|
| **目的** | 转化 |
| **核心内容** | 邮箱一键复制、社交链接、简短说明「可聊 AI 产品 / 合作」 |
| **交互** | mailto 优先；表单可选（降低首版复杂度） |
| **元素** | 邮箱 / 微信 / LinkedIn / 简历下载 |

---

### Footer

- 版权与年份
- 极简社交链接复述（可选）
- 不放多余营销模块

## 滚动与阅读路径

1. **0–5s：** Hero 建立「AI PM + 能 ship」印象  
2. **5–20s：** About + Capabilities 建立专业信任  
3. **20–45s：** Projects 用结果说服  
4. **45s+：** Skills 补充可协作信号 → Contact 转化
