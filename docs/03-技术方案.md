# 技术方案

## 技术栈

| 层 | 选型 | 理由 |
|----|------|------|
| 框架 | **Next.js 15（App Router）** | SSG/SEO、现代 React、便于日后加 MDX 项目详情 |
| 语言 | **TypeScript** | 类型安全、可维护 |
| 样式 | **Tailwind CSS v4** | 与 shadcn 配套、快速迭代视觉 |
| 组件 | **shadcn/ui**（Radix） | 可访问、可定制、不锁死设计 |
| 动效 | **motion**（framer-motion）或 CSS + Intersection Observer | 克制动效 |
| 图标 | **lucide-react** | shadcn 默认生态 |
| 字体 | `next/font` 加载 Geist | 性能与品牌一致 |
| 部署 | **Vercel** | 零配置、预览环境 |

## 关键实现要点

### SEO

- `app/layout.tsx` 配置 `metadata`（title、description、openGraph、twitter）
- 可选：Person JSON-LD 结构化数据
- 语义化 HTML：`header` / `main` / `section` / `footer`

### 性能

- 静态生成（SSG）优先
- 图片使用 `next/image`
- 字体通过 `next/font` subset，避免布局偏移
- 动效按需加载，尊重 `prefers-reduced-motion`

### 无障碍

- 锚点与键盘 focus 可见
- 对比度达标
- Sheet / Dialog 使用 Radix 焦点陷阱

### 分析（后期可选）

- Vercel Analytics 或 Plausible

### 简历

- 放置于 `public/resume.pdf`
- Hero 与 Contact 提供下载按钮

## 风险与取舍

| 决策 | 取舍 |
|------|------|
| 单页 vs 多页 | 首版单页，加载快、叙事连贯；项目极多时再拆 `/projects/[slug]` |
| 联系表单 | 首版 mailto + 社交；加表单需后端或第三方（Resend 等） |
| 深色默认 | 更贴 AI 创业者气质；可后续加主题切换 |
| MDX 项目详情 | 首版用 Dialog/Sheet + `portfolio.ts`；内容膨胀后再上 MDX |
