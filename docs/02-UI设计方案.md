# UI 设计方案

## 视觉方向

**关键词：** 冷静、精密、创始人感、少而准。

对标气质：AI 独立开发者 / AI 创业者个人主页——大留白、强排版、弱装饰、信息密度可控。

### 明确避免

- 紫白渐变网红风
- 暖奶油衬线 + 陶土色
- 报纸分栏排版
- 暗黑霓虹 / 满屏 glow
- 玻璃拟态堆叠
- Hero 内浮动 badge、统计条、促销 chip

---

## 色彩系统（CSS Variables）

首版建议 **深色主调**（更贴 AI 创业者主页），通过 token 预留主题切换。

| Token | 建议值 | 用途 |
|-------|--------|------|
| `--bg` | `#0B0F14` | 主背景（深石墨，非纯黑） |
| `--bg-elevated` | `#121820` | 次级表面 |
| `--fg` | `#E8EEF5` | 主文字 |
| `--fg-muted` | `#8B9BB0` | 次要文字 |
| `--accent` | `#3DDC97` | 主强调（青绿，科技但不 neon） |
| `--accent-soft` | `rgba(61, 220, 151, 0.12)` | 强调底 |
| `--line` | `rgba(232, 238, 245, 0.08)` | 分割线 |
| `--danger` | （表单错误用） | 错误态 |

**亮色备选：** `--bg #F7F8FA` + `--fg #0B0F14` + 同色 accent。

## 字体

| 角色 | 字体 | 说明 |
|------|------|------|
| Display / 姓名 | Geist 或 Satoshi | 几何无衬线，创始人感 |
| Body | Geist / IBM Plex Sans | 与 Display 同族优先 |
| Mono（标签/代码感） | Geist Mono / JetBrains Mono | 技能标签、指标数字 |

避免把系统默认栈（Arial / 系统 UI）作为主视觉字体。

### 字号阶梯（建议）

| 用途 | Desktop | Mobile |
|------|---------|--------|
| Brand / Display | 56–72px | 36–44px |
| Section Title | 32–40px | 24–28px |
| Body | 16–18px | 15–16px |
| Caption / Meta | 13–14px | 12–13px |

## Hero（第一屏）硬约束

- **一个构图：** 品牌名是英雄级信号，headline 不得压过品牌
- **内容预算：** 品牌 + 一句 headline + 一句支撑 + CTA 组 + 一层全宽氛围视觉
- **不做：** 首屏统计条、日程、地址、促销 chip、浮动 badge、inset 圆角媒体卡
- **背景：** 深色底 + 细网格 / 低对比噪点 / 缓慢光带（CSS/SVG）；若有实景图则全 bleed
- **无 Hero 浮层标签：** 不在主视觉上叠加 detached label / sticker

### Hero 文案骨架

```
[Brand]
[Headline — 一句]
[Support — 一句]
[Primary CTA]  [Secondary CTA]
```

## 各区块视觉处理

| 区块 | 布局 | 说明 |
|------|------|------|
| About | 左文右图（桌面）/ 上文下图（移动） | 大段文字 + 3 条原则列表；图为真实锚点 |
| Capabilities | 4 列 → 2 → 1 | 细分割线分区，少边框；线性 SVG 图标，克制 |
| Projects | 纵向列表或 2 列 | **允许卡片**（交互容器）；封面/缩略 + 标题 + 结果数字；悬停「查看」 |
| Skills | 三列分组 | 标签云式；熟练度用短横线或 muted 文字，不做彩虹进度条 |
| Contact | 居中短文 + 链接行 | 大邮箱、社交文字并列；Footer 极简 |

### Cards 使用原则

- **默认不用 Card**
- Hero / About 主内容禁止 Card
- 仅当容器承载用户交互时使用 Card（如 Projects 详情入口）
- 去掉边框/阴影/圆角后若不影响理解，则不应做成 Card

---

## 动效（2–3 个有意运动）

1. **Hero 入场：** 品牌与文案 stagger fade-up（约 400–600ms）
2. **滚动显隐：** 各 section 标题 + 内容用 Intersection Observer 轻量 fade-in
3. **Projects 悬停：** 轻微 `translateY` + 边线 accent 高亮

**不做：** 视差轰炸、粒子满屏、无意义无限循环动画。

## 响应式断点

| Token | 宽度 |
|-------|------|
| `sm` | 640px |
| `md` | 768px |
| `lg` | 1024px |
| `xl` | 1280px |

- 内容最大宽：`max-w-6xl` 或约 `1120px`
- 左右内边距：`px-6`
- 移动优先：导航折叠、Hero 字号阶梯、项目单列

## shadcn/ui 组件使用边界

| 组件 | 用途 |
|------|------|
| Button | CTA、导航 Contact |
| Sheet | 移动端导航 |
| Dialog / Sheet | 项目详情 |
| Badge | 技术标签、角色标签 |
| Separator | 区块分割 |
| Accordion（可选） | Capabilities 展开细节 |
| Tooltip | 技能补充说明 |
| Input + Textarea（可选） | 联系表单 |

---

## 间距与节奏

- Section 上下间距：桌面 `py-24`～`py-32`，移动 `py-16`～`py-20`
- 区块内标题与正文：`gap-4`～`gap-6`
- 强调「呼吸感」：宁可少内容，也不挤满一屏

---

## 无障碍与可读性

- 正文与背景对比度满足 WCAG AA
- 焦点态可见（键盘导航）
- 动效遵循 `prefers-reduced-motion`
- 提供「跳过导航」链接（可选但推荐）

---

## 设计交付检查清单

- [ ] 去掉导航后，第一屏仍能识别品牌
- [ ] Hero 无统计条 / 浮动 chip / inset 媒体卡
- [ ] 主色非紫白渐变、非奶油陶土风
- [ ] 至少 2–3 个有意动效，无噪声动画
- [ ] 桌面与移动均可完整浏览六大区块
- [ ] Projects 以外区域不滥用 Card
